📖 Project Description
This project is a modern and responsive restaurant website developed as part of my internship Task 3. The website is designed to help customers learn about the restaurant, explore the menu, and contact the restaurant easily.

🎯 Project Objectives
Create a professional online presence for the restaurant.
Showcase food items and services.
Improve customer engagement.
Provide easy access to contact and location details.

✨ Features
Responsive and user-friendly design
Attractive homepage
Food menu section
About Us section
Contact Us section
Restaurant location information
Mobile-friendly interface
